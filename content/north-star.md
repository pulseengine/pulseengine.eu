The goal keeps moving further out; only the steps toward it are dated. Inside, work flows through Kanban and gates. Each monthly varve layer is a measurement point, so progress becomes a curve. Every objective names its indicator and a guard metric, because agents work on whatever a gate checks. An objective that no script measures yet says **unmeasured**, not zero.

A rivet feature in any repository links up to the objective it serves with `serves: O2`. New ideas start as issues labelled `idea`; triage either links them to an objective, parks them, or closes them with a reason.
